# 🖥️ wscheck — Workstation Health Check CLI (Python)

`wscheck` est un **outil CLI d’automatisation IT** développé en Python, conçu pour **évaluer la santé d’un poste de travail Windows**.

Il permet de :
- vérifier l’état **système** (CPU, RAM, disque, uptime)
- tester la **connectivité réseau** (DNS, HTTP, connectivité externe)
- contrôler la présence de **process applicatifs critiques**
- générer un **score de santé global**
- exporter des **rapports JSON / CSV**
- s’intégrer facilement dans des scripts IT (grâce aux exit codes)
